每轮对比取该版本两次测试的平均吞吐量，除以同一轮默认版本的平均吞吐量。

TP=4、并发 4、ISL=32768、OSL=1024、随机长度比例 0.8、客户端 seed 42。每次吞吐测试测量 40 个请求并预热 8 个请求，启用缓存清理。640 个测量请求全部成功，各次输入/输出 token 总数完全一致，缓存命中率为零。测量耗时不包含模型加载及预热。

第一轮依次运行默认、仅卷积、仅 GDN、双内核，第二轮顺序相反。每组均通过 `run_server_both.sh` 启动新服务器，并设置相应的 FLYDSL_CONV、FLYDSL_GDN。默认版本保留原服务器已有调优，关闭两个自定义替换。反向顺序可减弱线性时间漂移影响，但无法消除所有调度、频率及接受长度波动。两个服务进程内的四次测试不能视为四次独立的服务启动实验。

保留脚本的模拟 MTP 接受长度目标 3.39，表中报告实际采样接受长度。结果是模拟接受率下的吞吐测量，不是质量评估。TTFT、TPOT 都不是内核直接计时。

第二轮每个版本完成吞吐测试后，另运行 GPU-only profile，测量四个请求并预热四个请求，保持 ISL=32768、OSL=1024，将采集限制为 12 个 forward step。profile 耗时不能作为吞吐测量。

参见 [summary.json](summary.json)、[metadata.json](metadata.json) 和 [run.sh](run.sh)。原始结果及日志按轮次、版本、测试编号保存。每次测试的编译计数包含其预热阶段，启动和 profile 阶段另计。复现时使用新目录，不要向已有结果追加记录。

## 结论与 profile 证据

双内核相对默认版本的吞吐中位数变化为 +0.20%，仅卷积为 +0.10%，仅 GDN 为 -0.43%。测量范围重叠，按每轮平均吞吐比较时，双内核从第一轮 +0.73% 变为第二轮 -0.08%，不能证明稳定的端到端加速。仅 GDN 在两轮中都略低，但 GPU profile 中该内核本身更快；现有数据不能进一步分离 host、调度及接受长度的影响。

| Profiled kernel | Default median (µs) | Both kernels median (µs) | Ratio |
|---|---:|---:|---:|
| Causal prefill convolution | 240.49 | 103.12 | 2.33× |
| GDN chunk_h | 849.74 | 783.23 | 1.08× |

表中先取每个 TP rank 的调用耗时中位数，再取四个 rank 的中位数。每条 trace 均包含 180 次卷积和 180 次 GDN chunk_h 调用。标称请求长度相同，但不同版本的打包略有差异，因此这是服务采样 profile，不是精确固定形状微基准。两个自定义内核都显示为 `kernel_0`：卷积通过 block [128,1,1] 及通道 grid 维度 12 或 24 识别；GDN 通过 block [256,1,1] 及 grid 前两维 [16,8] 识别。原内核名称为 `_causal_conv1d_fwd_kernel` 和 `chunk_gated_delta_rule_fwd_kernel_h_blockdim64`。

仅 GDN 的 TP3 和双内核的 TP0 trace 中，各有孤立的约 236 ms 卷积事件，原因尚未确定。这些样本保留在 [profile_summary.json](profile_summary.json) 中，统计使用中位数而不删除样本，也不将耗时总和换算为吞吐收益。trace 中还有大量 NCCL 通信及矩阵/MoE 内核工作，因此两个 prefill 操作变快不一定显著改善生成 1K token 的完整负载。各版本实际采样接受长度也不同，见吞吐表。仅凭 GPU-focused profile 无法对 host 开销作因果判断。

640 个吞吐测量请求全部成功，每次测试均输入 1,184,722 token、输出 36,717 token，缓存命中为零。启用 GDN 的服务进程共记录 68,220 次调用，包含启动、预热、吞吐及 profile，全部使用 FlyDSL，无回退。八个服务进程的两次计时测试，在预热后的缓存清理之后均没有编译调用。计数器也包含已有 AITER FlyDSL 代码，不仅统计自定义内核。

初始 GPU 快照为空闲。部分服务器切换后的即时快照仍有残留分配，但没有列出使用 GPU 的 KFD 进程。模型加载后，八组在 draft 加载完成时均报告 225.26–225.38 GB 可用显存，与残留分配在测量前释放的情况一致。最终每张 GPU 仅分配约 298 MB。源码哈希保持不变。本次重跑未观测到竞争的 MoE 工作负载，但没有使用持续的独占访问机制。

详见 [validation.json](validation.json) 和 [profile_summary.json](profile_summary.json)。所有服务器均已停止；中断实验单独保留，不计入本次结果。
